📦 APT Package System

The official package archive distributing compiled CLI binaries and daemons for Debian/Ubuntu distributions. Signed cryptographically with GPG keys for security.

Setup Options

  • Automatic Install: Run the unified shell script wrapper to trust keys, add repository lines, and install package dependencies automatically.
  • Manual Installation: Download GPG keys and write `/etc/apt/sources.list.d/m3tal.list` lines manually.
