⚙️ M3TAL Core

The primary service coordinator daemon and TUI shell command interface. Responsible for system lifecycle management, routing rules execution, configuration stores, and service diagnostics.

Primary Functions

  • Wraps and runs multi-container deployment instructions using Docker Compose V2.
  • Monitors container state transitions and writes event histories to the local SQLite state engine.
  • Generates load balancer routing definitions and secures Traefik certificates automatically.
  • Exposes secured JSON REST endpoints on port 8080 for dashboard communication.
